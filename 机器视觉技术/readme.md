## 备考建议

期末题型可能包含选择、判断、简答、计算/解答和编程题。2026 年回忆中出现过的内容包括：滤波与噪声、灰度级范围、距离度量、HOG、OTSU、采样、卷积层输出尺寸与参数量、CNN 各层作用、ResNet 基本块、Canny 与 Sobel、SIFT 特征匹配、形态学开闭运算等。

复习时建议：

1. 先把 PPT 的核心概念过一遍，尤其是二值图像、特征检测、CNN、分类与检测部分。
2. 对常见算法要能说清楚“做什么、为什么、怎么做”，例如 OTSU、Hough、Canny、SIFT、ROI Pooling。
3. 计算题重点练卷积输出尺寸、卷积层参数量、batch size / epoch / iteration 的换算。
4. 编程题不要只背函数名，至少要能写出基础的滤波、Sobel 边缘检测、简单 CNN/ResNet 模块。
5. 往年题和回忆题用来参考题型，不要把它们当作唯一复习范围。

## 课程建议

1. 深度学习部分大作业建议根据数据集情况选择合理的方式，一般受限于数据集规模需要使用迁移学习，也可以进行元学习/小样本学习的探索
2. 深度学习作业注意一定要划分数据集
3. 对于传统视觉部分，更建议掌握相关概念与技术
4. 深度神经网络部分推荐cs231n的lecture notes和assignments，深度学习的部分如果想学好一定要自己动手做写pytorch代码，掌握某种网络的最好方法就是自己手写一个；此外中文网课推荐北京邮电大学鲁鹏老师的计算机视觉研究生课，鲁鹏老师应该是国内教授计算机视觉相关部分的天花板了，是一位严谨且有能力的老师；
5. 入门书籍推荐动手学深度学习(鱼书)，从最基础的感知机一步步到神经网络，整本书非常浅显易懂
6. 其他学习资源：李沐动手学深度学习，小土堆pytorch教程，B站堂吉诃德拉曼查的英豪相关论文视频
7. 后续学习课程推荐: 学长学长，想让机器人等看懂视觉怎么办: Stanford cs224n Deep Reinforcement Learning; 学长学长，数据集少之又少怎么办，让神经网络学会学习,多任务学习又怎么办: Stanford cs330 Deep Multi-Task and Meta Learning, 这两门课都是由大名鼎鼎的Chelsea Finn所教授的，推荐有志于做相关领域科研工作的同学继续学习
