本目录收录机器视觉技术课程的往年卷子，以及根据复习材料重新整理、编译的专项练习题合集。

| [机器视觉技术练习题合集（含答案版）.pdf](./机器视觉技术练习题合集（含答案版）.pdf) | 保留完整参考答案与计算过程，共 65 页，适合订正和考前复盘。 |

## 练习题合集内容

合集共整理 118 道题，按四编组织：

1. 模拟练习卷（一）：24 题；
2. 模拟练习卷（二）：24 题；
3. 深度学习专项题库：36 题；
4. Faster R-CNN 专项题库：34 题。

内容覆盖传统图像处理、特征检测、形态学、CNN 组成与训练、AlexNet、VGG、GoogLeNet、ResNet、U-Net，以及 Anchor、RPN、Proposal、ROI Pooling 等目标检测重点。整理时已对重复输入去重，并校正了部分明显的公式、矩阵和计算结果提取错误。

## 建议使用方式

1. 先使用练习版独立完成题目，计算题写出完整公式和中间步骤；
2. 再对照含答案版订正，并标记概念混淆、公式错误和代码遗漏；
3. 最后使用两份原有卷子进行限时训练，检验知识迁移与答题速度。

## LaTeX 编译

源文件应使用 XeLaTeX 编译。默认生成含答案版，连续编译两次可正确生成目录：

```bash
xelatex 机器视觉技术练习题合集.tex
xelatex 机器视觉技术练习题合集.tex
```

若需生成练习版，请取消源文件开头的以下注释，再使用 XeLaTeX 编译：

```tex
\def\PracticeEdition{1}
```

编译环境需要提供 `ctex`、`tcolorbox`、`fvextra`、`needspace`、`hyperref` 等常用宏包。
