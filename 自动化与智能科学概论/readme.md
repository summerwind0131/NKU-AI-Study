# 自动化与智能科学概论
必修的专业选修课
感谢fyr同学提供的宝贵资料
## 课程概览
了解智能科学和自动化的主要研究内容+培养文献搜索整理与写文章的能力，主要出现在大二和已成为历史的特色班大一的课表里
## 学习书籍
ljt老师的《自动化与智能科学概论》

## 推荐网课
无

## 考核方式/难度
每周写一篇小论文，期末写一篇大论文（下图是开学初的要求，期末报告在学期末的时候改成了现场上交手写版）

## 学习方法
1. 课前会让看预习视频，会记分
2. 关于教材：不用看懂每个方程和每句话，理解里面所有的技术是不可能的，大概对里面的技术概念之类的有个印象就行
3. 写小论文的小技巧：
    1. 确定一个方向，然后在知网上找一个博士论文，去看它的研究综述（一般就是科普介绍）里面的引用文献（一般比较权威），抄一抄综述，然后去查引用文献的内容
     2. 借助合适的数据库：IEEE等等
     3. 去查教材里面的引用
4. 论文的评价标准：论文分两种，可以总结教材内容，也可以做拓展问题的研究。
    1. 总结教材内容：逻辑条理清晰就行
    2. 拓展问题研究：这个需要查论文，能查到权威论文基本上就可以对概念有很好的阐释，如果能查到比较先进的研究方向或者别人一般查不到的内容，结合一些自己的理解，创新型就会高一些。
    3. 这个评价标准只是我自己摸索出来的，并不适用于全部情况
    4. 注意格式要求
## 心得体会
1. 作为一个专业选修课（也就是D课），这门课的学习难度并不高，但拿高分也不是一个轻轻松松的事情，2学分，拿到4.0是需要有付出和态度的，这门课上拿到低分的同学也是大有人在
2. 教课的ljt老师是非常认真的老师，所以他对学生要求也很多，这些要求包括但不限于：
     1. 每周写一篇1000字左右小论文，学期总成绩就是由这些论文的分数构成
     2. 期末手抄论文（本人抄了一下午。。。。。）
     3. 不能用AI，被识别出来这篇论文就是0分
3. 课程的教学方式是模仿国外的方式：期末不考试+平时论文（会给提供论文相关的思考问题），这样的课在国外有很多
4. 尽管本人每周写论文都花不少时间，但是收获很大，如果认真对待这门课，不把它当作一个水课，那么对于专业认识和综合能力提升都很有帮助。但如果水过去，很可能分数就不会很高。
