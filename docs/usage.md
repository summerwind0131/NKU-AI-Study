# 使用指南

## 如何使用资料

先读课程 README，再看课件、往年题、实验报告或代码。课程资料通常来自不同年份、不同老师和不同同学，使用时要对照当年课程要求，不要默认所有内容都适用。

建议的阅读顺序：

1. 查看课程 Wiki 页面或课程目录下的 README。
2. 浏览课件目录，确认本年度讲授范围。
3. 用往年题和回忆题熟悉题型，不把它们当作唯一复习范围。
4. 参考实验报告和代码时，先理解任务要求和实现思路，再写自己的版本。

## 如何贡献

欢迎补充课程经验、资料说明、错题提醒、实验环境说明和高质量学习资源。贡献内容时建议：

- 保持描述客观，区分事实、个人体验和推测。
- 写清资料适用年份、老师或考核方式。
- 不上传侵犯版权、隐私或学校规定的内容。
- 不提交可直接替代他人作业的“交差式答案”。

## 学术诚信

本仓库的定位是学习交流和资料导航，不是代写或抄袭材料库。实验报告、课程设计代码和复习资料可以帮助理解思路，但不能直接照搬提交。

请特别注意：

- 不要把他人实验报告、代码、论文或作业改名后提交。
- 不要伪造实验结果、数据或引用。
- 不要倒卖本仓库资料。
- 如果课程有明确的资料使用限制，以当年老师和学校要求为准。

## 资料边界

仓库内容无法保证完全正确，也无法保证覆盖所有年份、所有老师和所有考核变化。遇到冲突时，以课程群通知、任课老师要求和官方教学平台为准。
