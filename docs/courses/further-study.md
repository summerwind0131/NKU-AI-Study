## 课程 / 栏目介绍

> 主要参考：`升学/readme.md`、`升学/保研/readme.md` 和顶层文件名。

升学不是课程页，而是保研、出国等信息的资料型归档栏目。根 README 目前只说明这里会记录相关信息，且仍在完善中；当前仓库中可见的实体资料主要是保研分享 PDF。
