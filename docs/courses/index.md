- 第一批课程精修：`机器视觉技术`、`线性代数`、`高级语言程序设计2-1`、`离散数学`、`高等数学A上`、`高等数学A下`、`概率论与数理统计`。
- 第二批入口补强：`大学物理`、`数据结构`、`机器学习`、`学海无涯`、`痴人喃喃`。
- 第三批入口补强：`中国近现代史纲要`、`运筹学`、`自动化与智能科学概论`、`升学`、`大物实验报告`。
- 后续可继续补强：`马克思主义原理`、`思想道德与法治`、`电路基础`、`高级语言程序设计2-2` 等页面。
