## 课程介绍

> 主要参考：`模拟电子技术/README.md`、`模拟电子技术/实验报告-fyr/README.md`、目录和文件名。教材评价、网课推荐和备考策略来自 README 中的个人经验，只能作为历史参考。

根 README 提到课内教材为华中科技大学《模拟电子技术》，并推荐对照清华大学童诗白版《模拟电子技术基础》：清华版“先讲器件再引入放大器”的叙事更顺，对电路设计思路的讲解也更多。README 同时提醒，华科版配套习题册个别答案有误，做题时需要自行甄别。

网课方面，README 推荐上海交大郑益慧老师的模电课程，认为其对电路设计背后的工程思维讲得很深入；Caltech Hajimiri 的 New Analog Circuit Design 偏器件物理，适合有物理基础、想深入理解器件原理的同学拓展。

## 备考 / 实验提醒

- README 记录 2026 年“范围是作业题”，但前面二十多道选择题考了很多细碎知识点，考前最好过一遍课本。每年重点可能不同，请以当年通知为准。
- 实验不用每次都写报告，有报告的多为按模板填数据；期末需要一份手写报告。
- 实验前先检查实验台器件是否完好，README 中提到坏器件导致大量调试时间的教训。
- 实验报告中的数据必须来自自己的实验，历史报告仅供参考，不要照抄。
