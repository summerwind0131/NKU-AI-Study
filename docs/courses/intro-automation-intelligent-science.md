## 课程 / 栏目介绍

> 主要参考：`自动化与智能科学概论/readme.md`、`作业/`、`教材/` 和现有分析 CSV。

根 README 把这门课定位为了解智能科学和自动化主要研究内容、培养文献搜索整理与写作能力的课程。页面也记录了 2026 年更新：成绩结构曾调整为作业成绩为主、平时签到为辅，作业成绩在小雅课程中可见。不同年份要求可能变化，实际仍以当年老师说明为准。

从资料结构看，这门课不是传统刷题型课程，而是教材阅读、每周小论文和期末论文/大作业驱动的课程。Wiki 页的重点应放在“如何理解资料、如何找文献、如何避免违规提交”，而不是把作业文档当成可复用模板。

## 使用建议

- 先读 README 的学习方法，再看教材目录选方向；这门课更强调阅读、整理和写作，不适合按刷题课复习。
- README 提到论文可以总结教材内容，也可以做拓展问题研究。选择拓展问题时，应优先查可靠论文和教材引用，而不是拼接网络材料。
- 作业目录中的 DOCX 只能用来理解题目形式、结构和深度，不要直接复用他人文章。
- README 明确提醒过 AI 使用风险；如果当年老师有 AI 使用规定，应严格按当年要求执行并保留自己的阅读、检索和写作过程。
- 这门课适合提前了解自动化、智能科学、机器人、深度学习、强化学习等方向，但不用在入门阶段追求读懂每个公式。
