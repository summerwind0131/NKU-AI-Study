## 课程介绍

> 主要参考：`电路基础/README.md`、目录和文件名。考试题型、成绩组成及难度评价来自 README 中的 2026 年回忆和个人经验，只能作为历史参考。

电路基础主要训练基本电路的分析方法。根 README 将课程主线概括为基尔霍夫定律与元件伏安关系（VCR）：网孔电流法等方法可以理解为方程组的变形，正弦稳态分析则会引入复数运算。沿着这条主线理解不同方法之间的关系，比孤立记忆公式更容易处理变形题。

仓库资料包括分章 PPT、样卷和电路实验报告。README 还推荐邱关源、罗先觉《电路》，并将考研题和英文教材列为进阶材料；这些拓展材料难度和用途不同，期末准备应优先回到当年课件与样卷。
