## 课程介绍

> 主要参考：`毛中特/README.md`、`毛中特/2026 毛概回忆.md`、目录和文件名。考试形式和背诵方法来自 README 中的 2026 年经验，只能作为历史参考。

根 README 提到，毛中特期末现在改为抽题考试，并由两个校区一起流水阅卷，因此任课老师对期末成绩的影响不大；2026 年统一划了重点，按重点背诵即可。

README 还分享了一种背诵方法：考前一周左右利用零碎时间，对照教材整理一份符合自己思路、字数尽量少的提纲；考前一晚照着提纲自己解释着背，不会的再看书，第二天早上再过一遍。
