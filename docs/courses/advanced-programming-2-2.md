# 高级语言程序设计2-2

## 课程介绍

> 主要参考：`高级语言程序设计2-2/README.md`、目录和文件名。2024 届机试题型、难度与成绩体验均为个人记录，不代表后续学期安排。

高级语言程序设计2-2 延续 C++ 基础，仓库 README 将主要内容概括为类与对象、继承与多态、模板与 STL、输入输出流。课程考核通常同时涉及笔试、机试和学期大作业，因此准备时需要区分三条线：笔试关注概念与代码阅读，机试依靠实际编码，大作业则依赖项目完成度和报告表达。

仓库已经提供课件、练习题、上机题、往年题和知识点总结，适合从课内知识框架逐步走到独立编码。README 还推荐 Stanford CS106L 和黑马程序员作为扩展入口；它们适合能力提升，但不能替代当年课件和考核要求。

## 备考 / 作业提醒

- 笔试：README 记录的形式包括选择、改错、读程序写结果和手写程序。复习时重点检查输入输出格式、构造与析构顺序、继承和多态等容易混淆的细节。
- 机试：2024 届个人记录涉及类、多态和简单链表。题型会变化，训练重点应放在独立编码、调试和时间管理上。
- 大作业：尽早确定范围、拆分功能并持续整理报告。项目创意和展示可以加分，但正确性、可运行性和真实贡献是基础。
- 往年答案和现成代码只能用于检查思路；未经理解的复制粘贴既不提升能力，也可能构成违规提交。
