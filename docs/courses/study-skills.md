# 学海无涯

## 课程 / 栏目介绍

> 主要参考：`学海无涯/README.md`、`学海无涯/LaTex使用教程/readme.md` 和顶层资料文件名。根 README 只有简短占位，本页主要按目录和文件名整理。

学海无涯不是具体课程，而是学习方法、工具使用和成长经验资料的归档栏目。当前资料包含 LaTeX 使用教程、自学经验、提问方式、编程能力提升、计算机专业学生提升指南和留学申请指导等。

这个栏目适合在“遇到具体学习工具或方法问题”时查阅，不需要像课程页一样从头读完。

## 使用建议

- 写实验报告或论文排版时，优先看 LaTeX 教程；README 推荐 Overleaf、官方文档、模板和现用现查。
- 遇到技术问题时，先看“提问的智慧”和“初学阶段常见问题”，再去问同学或老师。
- 编程、计算机专业成长和自学经验类资料适合长期规划，不适合临时抱佛脚。
- 该栏目资料来源和年份可能复杂，阅读时注意辨别适用场景。
