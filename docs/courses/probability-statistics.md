# 概率论与数理统计

## 课程介绍

> 主要参考：`概率论与数理统计/README.md` 与仓库顶层目录。Wiki 只做导航和经验整理，不展开 PDF、DOCX、PPTX 内容。

概率论与数理统计是工科试验班的重要专业必修课，根 README 也提到保研会涉及相关知识。课程可以粗略分成两部分：概率论关注把随机事件和结果建成数学模型，数理统计关注统计思想和统计模型。

README 判断这门课期末难度不算高，但公式、积分计算、作业正确率和计算器使用都很实际。想稳妥复习，应该先建立公式和题型框架，再用作业题、往年题和 PPT 检查细节。

## 备考 / 作业提醒

- README 记录的考核方式为平时 20% 加期末 80%，且期末可以带计算器，计算量不小时必须提前准备。
- 平时作业正确率会计入成绩，建议每次作业自己写一遍，再用答案检查不会的知识点。
- 期末可能出现《吉米多维奇》相关原题或类似题，老师 PPT、作业和往年题应优先于泛泛刷题。
- 概率公式可以速记，但统计部分更需要理解模型和适用条件，避免只背结论。
