# 概率论与数理统计

## 课程介绍

> 主要参考：`概率论与数理统计/README.md`

### 课程概览

- 工科试验班一门专业必修课，保研也会涉及到相关知识点，课程知识也较为重要
- 概率论：如何把事件发生的可能，变成数学的模型，把事件的结果以数学变量表达出来，并计算概率
- 数理统计：统计学的基本思想和统计模型

### 推荐书籍

- 仅就期末拿到4.0来说，老师的PPT+吉米多维奇足矣
- 拓展阅读可以阅读陈希孺的概率论与数理统计，会有拓展内容
- 关于课本：浙大概率论 课本+习题册

### 概率论

- b站上框框老师的概率论还是不错的，如果想规范做题步骤可以看一看他讲例题

### 统计学

- Z Statistics 的视频，非常注重Intuition
- https://www.zstatistics.com/
- 白话统计学（xhs上面的）
