## 课程介绍

> 主要参考：`自动控制原理/README.md`、`自动控制原理/往年真题/README.md`、`自动控制原理/自控实验 by fyr/README.md`、目录和文件名。

根 README 推荐 DR_CAN 的自动控制原理系列视频，认为其从生活中的例子出发、由浅入深，讲解非常出色；DR_CAN 的《控制之美》也值得一读。自控的数学基础内容较多，感兴趣可以同步学习信号与系统，了解卷积、傅里叶变换、z 变换等内容。

README 认为这门课更需要在理解概念的基础上做练习，每年题型相对固定；小题理解概念后难度不大。建议提前熟悉计算器的数值求解功能，例如计算根轨迹分离点时可以直接数值求解分式方程。
