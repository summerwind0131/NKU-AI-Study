## 课程介绍

> 主要参考：`线性代数/README.md` 与仓库顶层目录。Wiki 只做导航和经验整理，不展开 PDF、DOCX、PPTX 内容。

线性代数是大一阶段重要的数学基础课，后续离散数学、自动控制等课程都会反复用到。根 README 强调，这门课不只是矩阵计算，还应建立“方程组、矩阵、行列式、线性空间”之间的整体观念。

如果课堂讲授不适合自己，README 建议尽早调整方法，可以结合网课、自学教材和练习题补足理解。期末备考可以更务实：先确认本年课程范围，再用往年题和相关习题熟悉题型。
