# 线性代数

## 课程介绍

> 主要参考：`线性代数/README.md`

### 课程概览

- 线性代数是大一同学一门入门的数学课，在未来的学科学习中扮演着重要的角色，后续的离散数学，自动控制等等课程都会涉及到线性代数，如果现在不学好将来大概率会后悔再重学一遍。同时线性代数也有着巨大的魅力，如果深入学习就可以体会到线性代数的优美之处！
- 并且这门课可以说是大一同学第一门专业课之一，工科大类讲得好的老师可以说是寥寥无几，建议大家尽快摆脱高中思维，选择网课/自学等适合自己的方法，如果听不懂千万不要只认为是自己的问题！！，及时调整学习方法。

### 考核难度

- 南开大学工科试验班线性代数的考核难度不是很高，个人认为即使考前突击学习，针对性练习往年试卷与相关习题就能拿到4.0

### 网课推荐

- MIT 线性代数课，非常经典的一门课程
- 清华大学lsq老师的线性代数课，这是面向2024清华大学电子系学生开设的线性代数课，难度与内容范围比南开大学略高，且讲授顺序不同，如果期末对着这门课突击大概率会误入歧途，推荐有更高追求，学有余力的同学平时学习，是本人非常喜欢的一门课程，刘老师在B站的账号是 我真的不懂分析
- 丘维声高等代数，难度更高

### 学习书籍

- 课本：高等数学 第三册 川大版（就是个提纲）
- 同济线性代数习题册：可以用来平时刷题做，解题方法写得也挺细致的，但是和南开期末出题风格不一样，期末备考以往年题为材料就够了
- Linear Algebra Done Right：比较高视角的教材，可以用来补充学习
