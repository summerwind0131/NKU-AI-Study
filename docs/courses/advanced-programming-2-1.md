# 高级语言程序设计2-1

## 课程介绍

> 主要参考：`高级语言程序设计2-1/readme.md`

### 课程概览

- 应该是信息工科大类同学大学的第一门编程课，学习C++的一些基础知识

### 学习书籍

- 关于教材：计算机学院采用刘璟的C++程序设计，不是很好评价这本书，也不太理解为什么要用这本书
- 推荐书籍：
- 《C++ primer》

### 推荐网课

- 黑马程序员C++
- 浙大翁恺
- 直接上B站选播放量最高的

### 考核方式

- 机试+平时分+期末笔试（注意大类笔试极为逆天），一不小心就被创四了
- 机试与平时作业/练习题难度接近且略为简单，详情可见往年题
- 笔试要注意PPT上微小的知识点
