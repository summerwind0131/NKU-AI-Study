# Control Report Checklist

- Final filename: `<student_id>_<student_name>_控制实验<中文数字>.tex/.pdf`, for example `123456_张三_控制实验八.pdf`.
- Header metadata matches the user, not the DOCX reference author.
- Sections present: 实验目的, 实验内容, 实验原理与参数设计, 实验步骤, 实验结果与分析, 实验反思.
- PDF guide has been checked for experiment title, devices, steps, formulas, and parameters.
- DOCX images are extracted locally; selected figures are renamed descriptively.
- Formula-heavy content is typeset in LaTeX when practical.
- Result analysis compares before/after control effects and names error sources.
- `xelatex` passes twice; no missing graphics or undefined references.
- Rendered page check shows no missing figures, severe overflow, caption mismatches, or empty template sections.
