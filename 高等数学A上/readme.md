# 高等数学A上
## 课程概览
学习一元函数微分学，一元函数积分学，微分方程，近些年考核难度在不断上升
## 学习书籍
1. 关于课本：南开大学高等数学课本+南开大学高等数学习题课讲义
 个人认为南开大学高等数学课本还是可圈可点的，一些数学推导虽然有不太严谨的地方，但在直观性，帮助理解方面还是有一定优势的，此外也更贴合学校老师的授课顺序，也有不少经典的例题  --sfy
 此外，南开大学习题课讲义里面也有很多考研习题，天津市大学生数学竞赛题，难度从A-B-C依次递增，是本人比较喜欢的一本书  --sfy

## 考核难度
近些年难度不断增加，应该是给不少同学造成了不小的冲击，并且对于高等数学这样五学分，数学考试的课程来说，稍有不慎就会崩盘，对于大一GPA的影响也是巨大的。
难度的增加主要在于中档题，计算量方面，并没有太多非常难的题，即使有，适量的放弃最后也可以拿下4.0，因此备考重心应该放在中档题的练习，计算题的练习上，老师也明确指出侧重考察学生有没有经过大量的练习
## 备考建议
- 不建议平时一点不学然后期末速通，这门课速通还是有很大挂科概率的，期末卷面分低到一定程度谁也捞不上去
- 多刷题，吉米多维奇习题集，课本课后题，老师PPT上的题
- 重总结，多思考
- 不同于数学分析，高数最重要的是练习刷题，掌握解题技巧，因此要有大量的练习
- 难度的增加个人认为主要在计算量与中档题的占比上，因此就会出现“如难”的情况，如果不熟练，考场上就比较痛苦，实际上考后再看一看也没有难题
- 仅就拿高分而言，最重要的就是刷题，比如PPT/吉米多维奇/南开大学高等数学习题课讲义/课本课后习题
- 进阶学习：学习数学分析
