### 课程介绍
包括4个板块（其中1学时=45min）
在大一大二大三开展
大一稀里糊涂，大二会统一讲
课程内容和进展（完成的学时、活动次数）都可以在立公增能辅学平台上看见
就是这个网站：https://fuxue.nankai.edu.cn 
点击左侧边框可以看见**课业进展**、**课程大纲**，还可以在主题讲座下面申报参与的讲座

#### 三、实践活动
学时要求：三年不少于90学时
次数要求：不少于6次
这个实现方式包罗万象
1.  社会实践
     团体和个人都算，可以上南开社会实践的网站上去找活动，也可以在那个网站上申报个人活动然后自己去做，记得关注南开的各种公众号发布的志愿活动。
     常见的活动有：高中返校宣讲等等
     南开社会实践网站：http://shsj.nankai.edu.cn
     申报方法可以上小红书找Murf学长发的贴
2. 志愿活动
     可以参加学院组织的志愿活动、社团组织的志愿活动或者自己在志愿汇app上找
     学校组织的志愿服务记得签到和签退，会有专人登入时长
     自己做得志愿活动要自己上志愿服务平台申报，申报方法可以自己在微信里搜，很多学院都出过教程
     南开志愿服务管理平台：http://zyfw.nankai.edu.cn
3. 其他
     学院组织的企业参访、种大蒜种红薯等等
