## 📘 仓库简介

  从高中到大学，不仅是学习上的跨越，更是思维的跨越。刚刚步入大学的一年里，我们经历了太多的彷徨和迷惘，和课程绩点斗争，于信息差中侥幸存活，在学习和生活上都经历了一番考验。为此，我们想把自己的经验贡献出来给后来者作为参考，帮助更多的同学在大学中尽快地适应，同时真正体会到大学的乐趣。
  本仓库中主要包含课程学习、大学技能和心理调节三个板块，目前还在逐步更新中。

---
## 🧠 课程学习模块
-  在**课程学习**这一部分中，我们目前收集了**人工智能学院智能科学技术专业**部分课程的**学习经验、学习资料和期末试题**。需要注意的是，在使用**每门课程**的资料之前，**请仔细阅读该门课程的 readme 文档**，避免出现错用资料的情况。大学的课堂与考试和高中有很大的区别，你大概率会遇见许多讲不明白课的 ppt reader，读到许多晦涩难懂的课本，然后在期末面对一张非常难的试卷。我们无法改变学校这样的现状，但好消息是生活在信息时代的我们完全可以借助网上的资源脱离这一切，真正的学到一些有用的知识，而不是死板的背诵课本和ppt上的公式和题目，陷入盲目卷绩点的怪圈。希望在这一部分里，我们可以帮助更多的同学找到如何学习某个学科的方法，而不是局限于在某门课上拿高分。
内容包括：
- ✔ 学习经验总结  
- ✔ 推荐教材 / 网课 / 自学资源  
- ✔ 历年期末试题与复习建议  
- ✔ 课程踩坑指南  
- ✔ 每门课单独 README（请务必先阅读）

## 🛠 大学技能模块
- **大学技能**这一部分包含在**学海无涯**这一文件夹当中，我们汇总了一些大学常用的学习技能培养的教程文章，包括：
- 信息检索（如何查文献、如何用 Google 正确搜索）
- 学术排版（LaTeX / Markdown / Typst）
- 笔记与个人知识库构建
- 编程能力提升路径（从入门到工程化）
- 如何写出高质量实验报告与课程论文
📌 **目标：补足大学不教、但未来非常重要的“隐性课程”。**

## 🧘 心理调节模块
- **心理调节**这一部分包含在**痴人喃喃**这一文件夹当中，我们收录了例如《上海交大生存手册》等等优秀的文章本模块包括：
- 《上海交大生存手册》及优秀心理文章  
- 如何缓解焦虑、迷茫与内耗  
- 效率与心态之间的平衡  
这些文章有的讨论现行教育体制下大学生应当以什么样的心态学习生活，有的专注于一些常见的心理问题。设立这一部分的目的是为了给在那些大学中迷茫的同学亮一盏灯，提供心理建设上的帮助，从而以更加平和健康的心态在大学中找到人生中的方向。
我们的仓库还在不断完善当中，如果你也有想分享的经验或者独到的想法，欢迎联系我们！
