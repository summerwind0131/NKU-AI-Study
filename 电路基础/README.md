# 电路基础
考察简单的电路分析方法与技巧

电路基础实际本质就是基尔霍夫+VCR，该课程任何定律与分析方法都是建立在此两个方程之上附以数学技巧得到的，例如一系列网孔电流法等实际上是线性方程组的变形与变量的代换，正弦稳态电路的分析就是引入复数的运算等等，get到这一点，就可以学会将电路基础分析方法融会贯通，在遇到变型的题目时也可轻松拿下。
## 考核难度
易，将电路技巧融会贯通并适当练习即可应对期末考试

期末试题难度大致相当于样卷的难度，并且大概率有样卷非常相似的答题

（说来惭愧，考前两天才开始学电路最后4.0）

- 样卷做得不好也没关系，因为比较难的题型就样卷上那几种（本人考前样卷做得不好甚至觉得要挂了，最后也4.0）
## 考试内容（回忆版，以2026年为参考）
- 填空题8道题左右，有一定计算量，需要熟练掌握戴维南等效电路
- 三道等效变换：电阻+电感+电容
- 4道大题，主要集中于时域变换、耦合电感和傅里叶信号的综合题目，跟样卷上的大题差不多，还会出原题，所以样卷一定要好好做
- 考试可以带计算器，可能涉及到复数运算和线性方程组运算，可以上卡西欧官号学习一下
## 成绩组成
40%平时分+60%期末考试
## 推荐教材
- 国内教材邱关源，罗先觉的《电路》经典之作
- 想要巩固练习就可以看考研电路题例如《电路考研18讲》（偏难，期末考试难度达不到，期末考试难度就是样卷难度甚至偏简单）
- Electric Circuits, 12e (James Nilsson, Susan Riedel) ，一本还不错的英文教材，例题非常丰富，典型题目的方法总结很到位
