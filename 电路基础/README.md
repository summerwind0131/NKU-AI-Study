# 电路基础
考察简单的电路分析方法与技巧

电路基础实际本质就是基尔霍夫+VCR，该课程任何定律与分析方法都是建立在此两个方程之上附以数学技巧得到的，例如一系列网孔电流法等实际上是线性方程组的变形与变量的代换，正弦稳态电路的分析就是引入复数的运算等等，get到这一点，就可以学会将电路基础分析方法融会贯通，在遇到变型的题目时也可轻松拿下。
## 考核难度
易，将电路技巧融会贯通并适当练习即可应对期末考试

期末试题难度大致相当于样卷的难度，并且大概率有样卷非常相似的答题

（说来惭愧，考前两天才开始学电路最后4.0）
## 成绩组成
40%平时分+60%期末考试
## 推荐教材
- 国内教材邱关源，罗先觉的《电路》经典之作
- 想要巩固练习就可以看考研电路题例如《电路考研18讲》（偏难，期末考试难度达不到，期末考试难度就是样卷难度甚至偏简单）
