# 线性代数
## 课程概览
线性代数是大一同学一门入门的数学课，在未来的学科学习中扮演着重要的角色，后续的离散数学，自动控制等等课程都会涉及到线性代数，如果现在不学好将来大概率会后悔再重学一遍。同时线性代数也有着巨大的魅力，如果深入学习就可以体会到线性代数的优美之处！

并且这门课可以说是大一同学第一门专业课之一，工科大类讲得好的老师可以说是寥寥无几，建议大家尽快摆脱高中思维，选择网课/自学等适合自己的方法，**如果听不懂千万不要只认为是自己的问题！！**，及时调整学习方法。
## 学习建议
### 考核难度
南开大学工科试验班线性代数的考核难度不是很高，个人认为即使考前突击学习，针对性练习往年试卷与相关习题就能拿到4.0
### 网课推荐
1. MIT 线性代数课，非常经典的一门课程
2. 清华大学lsq老师的线性代数课，这是面向2024清华大学电子系学生开设的线性代数课，难度与内容范围比南开大学略高，且讲授顺序不同，如果期末对着这门课突击大概率会误入歧途，推荐有更高追求，学有余力的同学平时学习，是本人非常喜欢的一门课程，刘老师在B站的账号是  **我真的不懂分析**
3.  丘维声高等代数，难度更高
4.  3blue1brown的视频，里面有很多线性代数的几何化解释，理解抽象概念困难话可以看一看
### 学习书籍
1. 课本：高等数学 第三册 川大版（就是个提纲）
2. 同济线性代数习题册：可以用来平时刷题做，解题方法写得也挺细致的，但是和南开期末出题风格**不一样**，期末备考以往年题为材料就够了
3. Linear Algebra Done Right：比较高视角的教材，可以用来补充学习
4. 清华大学出版社《线性代数入门》，教材较新且有不错的例题，可以补充学习
5. 北京大学《高等代数解题方法》，涵盖很多习题
### 线代杂谈
不少同学初学线性代数可能有晦涩难懂的感觉，再加上某些老师上课随意的态度，导致大家丧失了对线性代数的兴趣，但实际上线性代数是一门富有魅力且十分重要的学科。不同于微积分，微积分的学习有一条相对清晰的脉络，微分和积分一句话就可以讲清，围绕着微积分基本定理展开，从逻辑上也更容易让人接受。线性代数则不同，如果你问线性代数的基本定理是什么，大概率很难得到一个简单的答案，一句话也很难讲清线性代数是什么，**实际上可以认为线性代数是由方程组，矩阵，行列式，线性空间这四个部分构成了基石，在此基础上，我们去研究特征值，内积空间，二次型，多重线性代数等问题，学习线性代数时要首先形成一个对于此的大致观念**，学习时要着重把握四个基石之间的相互关系，经常回顾并从不同的角度来看线性代数的这些部分。

此外，了解一些线性代数的历史也可以帮助理解
- stage 1 线性方程组阶段，公元前巴比伦人已经知道如何解线性方程组，《九章算术》也给出了解线性方程组的方法
- stage 2 行列式阶段，莱布尼茨求解线性方程组，发明了行列式的概念
  
          拉格朗日发现了行列式的性质
  
          克莱默提出了基于行列式的nXn线性方程组接法
- stage 3 矩阵阶段，Sylvester定义了matrix（matrix在拉丁语中有母亲，子宫之意，从中带着矩阵是行列式之母，行列式是矩阵之子，矩阵是能产生行列式的东西的观点）
          Cayley 定义了矩阵加法，数乘，单位矩阵等一系列概念
  
          Cauthy引入了特征值，矩阵的对角化，相似矩阵等概念
- stage 4 线性空间阶段，G Peano提出来线性空间的概念
- stage 5 模论阶段，Emmy Noether提出了模的概念

在学习线性代数时，先形成大体对于线性代数的理解与观念，在此基础上去学习，同时注意方程组，矩阵，行列式，线性空间之间的关系，并分别从不同的角度去看待这几个问题。同时，线性代数作为一门数学课，课后的练习投入也是必不可少的，需要题目的练习。
