## 课程介绍与学习建议

本学期课程主要介绍经典机器学习方法，内容建立在概率统计、线性代数和优化方法之上，包括回归、分类、聚类、降维等基本问题，暂不涉及深度学习。

经典机器学习并没有因为深度学习的发展而失去价值。相反，认真学习这些内容，可以帮助大家建立概率与统计直觉，理解模型如何从数据中学习，并为后续学习深度学习和开展科研打下基础。

在学习具体算法时，建议不要只关注公式推导和代码调用，还应重点理解以下问题：

- 模型为什么能够泛化到没有见过的数据；
- 什么是过拟合、欠拟合以及偏差—方差权衡；
- 正则化、特征工程和数据预处理为什么重要；
- 如何正确划分训练集、验证集和测试集；
- 如何使用交叉验证选择模型和超参数；
- 不同任务应该选择什么评价指标；
- 如何避免数据泄漏，并保证实验结果可以复现。

机器学习目前已经与众多领域产生了广泛交叉。许多传统领域中难以通过固定规则或解析模型解决的问题，都可以通过数据驱动的方法进行建模。从搜索、推荐、图像识别和语音助手，到医疗诊断、药物研发、金融风控和智能制造，机器学习已经成为现代社会重要的基础技术之一，与我们的日常生活密不可分。

## 推荐课程

推荐学习 Stanford CS229：Machine Learning。

CS229 是吴恩达教授主讲的经典机器学习课程，内容覆盖监督学习、无监督学习、概率模型和学习理论等主题。课程的 Lecture Notes 质量很高，对算法的数学原理、推导过程和适用场景都有较系统的介绍，适合作为本课程的补充材料。

学习 CS229 时不必一开始追求全部看懂。可以先结合本校课程进度学习对应章节，在掌握基本概念后，再进一步阅读相关推导和拓展内容。

## 实验与编程语言

建议大家在实验课中主动使用 Python 复现课程中的主要算法和实验。Python 已经成为当前机器学习科研、开源项目和产业实践中最常见的语言之一，许多高校的机器学习课程也早已要求使用 Python。尽早熟悉 Python，有助于后续参与科研、竞赛和工程项目。

推荐逐步熟悉以下工具：

- NumPy：矩阵计算和数值运算；
- Pandas：数据读取、清洗和分析；
- Matplotlib：数据与实验结果可视化；
- scikit-learn：经典机器学习算法、数据预处理、模型选择和评价；
- Jupyter Notebook：交互式实验和结果记录。

建议至少掌握一套完整的机器学习实验流程：

1. 读取并检查数据；
2. 清洗数据并完成特征处理；
3. 划分训练集、验证集和测试集；
4. 训练一个简单的基线模型；
5. 选择合理的评价指标；
6. 进行交叉验证和超参数选择；
7. 分析错误样本和模型局限；
8. 固定随机种子并记录实验配置。

不要只追求调用更多模型。一个数据处理正确、评价方式合理、结果可以复现的简单模型，通常比一个流程存在问题的复杂模型更有价值。

## 理论与实践

机器学习是一门理论与实践紧密结合的课程。只阅读教材和推导公式，可能会觉得很多概念比较抽象；只调用现成代码，又容易停留在“会用工具但不理解原理”的阶段。

建议大家在学习过程中：

- 手动实现一些基础算法，例如线性回归、逻辑回归、K-means 和 PCA；
- 使用 scikit-learn 完成标准化、交叉验证和模型评价；
- 尝试完成一个从数据处理到结果分析的完整项目；
- 参加 Kaggle 等数据科学竞赛，熟悉真实数据中缺失值、类别不平衡和评价指标等问题；
- 阅读优秀开源项目，学习规范的代码结构和实验记录方式；
- 对实验结果进行分析，而不是只报告最终准确率。

Kaggle 可以帮助大家提高数据处理和工程实践能力，但竞赛排名并不是学习机器学习的唯一目标。在课程项目和科研中，问题定义、实验设计、结果可复现性以及对模型局限性的分析同样重要。

## 推荐学习路线

对于刚接触机器学习的同学，可以参考以下路线：

1. 复习线性代数、概率统计和微积分基础；
2. 学习课程中的经典机器学习算法；
3. 使用 NumPy 和 scikit-learn 复现课程实验；
4. 完成一个较完整的小型机器学习项目；
5. 学习 CS229 等课程，进一步理解数学原理；
6. 根据兴趣进入计算机视觉、自然语言处理、数据挖掘、强化学习或 AI for Science 等方向；
7. 在掌握经典机器学习后，继续学习 PyTorch 和深度学习。

机器学习的知识体系非常庞大，不需要在一门课程中掌握所有算法。更重要的是建立正确的建模思维：理解数据、明确任务、选择合理的方法、设计可信的实验，并对结果保持审慎。
