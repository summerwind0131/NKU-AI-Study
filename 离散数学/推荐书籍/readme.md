学校的离散数学学得非常非常浅薄，对数学感兴趣的话推荐基本课外拓展书
### 教材相关
- MIT  - Mathematics for Computer Science
- Rosen - Discrete Mathematics and its application：课内PPT和教材的参考书籍，很多课后题考试题也是这本书里面的原题，例子很多，生动有趣
### 拓展相关
- **数理逻辑**：
    校内学得那点东西只能说是在闹着玩吧，推荐了一本还不错的逻辑证明书，可以补充阅读
- **集合论**：
    1. Tao分析里面关于集合论讲了不少，习题也不错，可以用来练习
    2. Naive Set Theory 有一些比较完整的介绍和数学的解释，难度相对大一些
- **图论**
     1. Introduction to Graph Theory 几乎所有涉及到的图论相关问题的完整解释里面都有，如果想找证明之类的可以在里面看
- **抽象代数**
    1. Chapter 0 是讲范畴论的，只看里面关于群的内容并能够完成习题（挺难的），你的水平就可以远高于期末考试代数系统最后一道题了
