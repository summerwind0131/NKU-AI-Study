# 课程内容
- 教材：Algorithm Design by Jon Kleinberg, Eva Tardos
     - 中文翻译版很烂，建议直接看原版教材，教材当中对于算法的证明非常详细，比PPT内容也更多，还是可以从中学到很多的。
     - 教材的课后题有一定难度，质量也还不错，熟练的话十分钟能做出来，刚开始做的话，思考一个多小时也是正常的
- 课内范围：教材的前八章
# 备考小策略
- 考试可能会比较难的地方就是贪心、分治和动态规划这三道题，但是期末一般会出一些比较经典的题目，不会像作业题那么难，所以把往年题目告诉ai，让它多出点类似难度的题会很有帮助。本人就非常幸运的做到了ai出的原题，直接开始默写（bushi。
- 此外过程一定一定要写的很清楚，需要写严谨的伪代码，最好别写文字（些文字的话只会给很少的分）；证明也是要完整清楚的证明过程，不要跳步，遇到严格的老师会扣分的。
