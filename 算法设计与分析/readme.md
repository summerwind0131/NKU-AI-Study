# 算法设计与分析
如果只是学习这门课程老师PPT所教授的内容，那么课程难度应该不大，相信同学们也能初步体会到算法的魅力与乐趣，但是这门课程最重要的是从中体会到算法的思想精髓，面对问题能够选择高效正确的算法，甚至对现有的算法做出改进，为科学进步做出贡献。

此外，算法的学习也是一个重要的总结与动手的过程，加深对某种算法理解的最好方式就是：去自己手写算法题的代码，如果大家能够刷完洛谷/力扣上有关某种算法的题单题目，相信大家的代码能力以及对算法的理解都会得到极大的提升。

## 各个章节简述
### chap1 引言
本章中需要掌握的为稳定匹配的算法思想，伪代码，相关证明

### chap2 算法分析基础
本章需要理解各种算法记号的定义，作用，用途；相关证明

### chap3 图
理解DFS,BFS,DAG等的算法流程，通过不同的数据结构（栈，优先队列，最小堆，队列）就能实现不同的功能，领会到数据结构的强大功能

### chap4 贪心算法
贪心算法的核心就在于能够通过提出一个贪心策略，并且证明这个贪心策略是最优的（核心）；因此需要理解贪心算法的证明方式，总结如何提出有效的贪心策略

### chap5 分治
分治的思想简单而优美有效，关键在于在合并子问题时，能够通过问题本身的性质来减小计算量（从递推关系式的角度也可以理解），其中的矩阵乘法/快速傅里叶变换等是最伟大最优美的算法之一，凝聚着算法的智慧与思想

### chap6 动态规划
动态规划的难度较大，也是算法竞赛的一道小坎，动态规划一般可以分为两个步骤：分析动态规划问题与提出有效的合并策略，关于分析大家可以去学习“动态规划闫氏分析法”，是浅显易懂的动态规划分析理论；关于策略，其实更多是经验总结与记忆的问题，不同于其他算法存在于灵机一动或灵光乍现，动态规划如果先前没有学习过某种合并策略，先推出来的难度很大，所以建议大家平时多总结动态规划的题型策略（oi wiki）

### chap7 网络流
网络流中最大流最小割定理其实是线性规划有关对偶问题的完美体现，从对偶问题的角度来看，最大流最小割定理是显然的，大家学有余力可以学习如何从凸优化到线性规划（对偶问题）到整数规划再到网络流的，此部分内容可以参考南京大学jyy的算法竞赛讲解

### chap8 NP与计算难解性
通过归约/等价的思想，就可以有效地分析问题难度，此外还有NP,P等问题
