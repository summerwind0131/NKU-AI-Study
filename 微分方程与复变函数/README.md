# 微分方程与复变函数
## 课程概览
- **微分方程**：《常微分方程》1-6章
- **复变函数**：《复变函数》1-6章
- 教材画星部分不怎么讲，也不怎么考
- 微分方程需要用到一些微积分和线性代数的知识，复变函数要算积分也比较多，如果基础不好可以提前补一补
## 学习书籍
1. 课本：
     - 中山大学版《常微分方程》
     - 四川大学版《复变函数》
     - 以上两本书的配套习题讲义
2. 推荐书籍材料：
    - 微分方程：
         - Elementary Differential Equations and Boundary Value Problems (William E. Boyce, Richard C. DiPrima etc.)：可以用来补充一些教材中没讲的内容
         - Differential Equations and Linear Algebra (Gilbert Strang) ：如果线性代数部分忘了，可以用这本书快速补一下
    - 复变函数：
         - Visual Complex Analysis 25th Anniversary Edition (Tristan Needham Roger Penrose (Foreword)) ：YouTube上有很多基于这本书做的可视化视频，可以找来看一看，内容远高于考试，可以根据自己的数学基础选择性阅读

## 考核难度
- 题目类型：判断题+选择题+大题
- 关于考试，老师考前会讲得比较仔细（考前那节课一定要去认真听一下），综合来讲属于记诵数学考试，还是比较简单的
- 老师强调的题、PPT上的题、除去老师说过不考部分的作业题和往年题，用来备考足够
## 学习难度与心得体会
- 单就常微分和复变来说，在理解上本身是很有难度的，不过教材上面的证明写得还可以，基础知识扎实的话只看教材也可以明白
- 这门课是大二下的自动控制原理数学准备课程，是需要认真学的
