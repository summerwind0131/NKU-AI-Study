# 军事理论
## 课程概览
较为逆天的一门课，学习军事理论的相关知识，多个学院集中上课，线上课+线下见面课+讨论课，没什么好说的，按照要求水过去就可以了
## 学习书籍
可认为无
## 推荐网课
无，但智慧树网课需要完成
## 考核方式
线上课完成情况+线下课出勤情况，答题情况+讨论课小组给分+线上期末考试+课程论文提交
## 注意事项/建议
- 线下课保证出勤与答题正确率，出勤与答题情况都会计入成绩
- 知到网课与期末考试记得完成（线上期末如果用AI正确率不高，但是是有满分途径的）
- 结课论文想拿高分注意不要AI味过于浓厚
- 小组展示建议注意一下老师线下课提及的展示注意事项（如果他强调过某个东西你又恰好没注意，又恰好展示遇到了他，可能会有点惨）
- 小组展示互评之前几个小组商量一下，都给对方打满分就行了（学生何必为难学生）
- 给分据说是有些玄学的，但绝大多数应该都是4.0
## 老师评价
不敢评价
