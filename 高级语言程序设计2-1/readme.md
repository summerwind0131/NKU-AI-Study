# 高级语言程序设计2-1
## 课程概览
应该是信息工科大类同学大学的第一门编程课，学习C++的一些基础知识
## 学习书籍
1.  关于教材：计算机学院采用刘璟的C++程序设计，不是很好评价这本书，也不太理解为什么要用这本书
2. 推荐书籍：
 - 《C++ primer》
 - 《C++ primer plus》
 - 《深入浅出程序设计竞赛》
## 推荐网课
- 黑马程序员C++
- 浙大翁恺
- 直接上B站选播放量最高的
## 考核方式
机试+平时分+期末笔试（注意大类笔试极为逆天），一不小心就被创四了
- 机试与平时作业/练习题难度接近且略为简单，详情可见往年题
- 笔试要注意PPT上微小的知识点
- 平时分只要作业提交且全部AC即可拿满
## 学习方法
个人认为C++的期末考核不能很好地反映一个人的真实水平，可以学习国外如MIT，Stanford的相关课程并完成作业（重要！！），相信你会对C++有一个不一样的看法
此外也推荐快速过完相关知识点，然后刷编程题，做题中学，学中做题，“如果把练习题都刷上两遍那么期末机试肯定是满分”，或者在网上找一些简单的编程小项目锻炼一下自己，毕竟编程课，能写出来代码才是最重要的
## 如何备考
- 机试考察硬功夫，多写练习题/作业题，一些经典的例如冒泡排序等一定要会写
- 笔试过PPT上的知识点，看雨课堂上的题
- 平时分一定要把作业拿到满分，不会写就是用AI也要拿到这个分(
