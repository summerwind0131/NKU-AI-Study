## LaTex使用教程
### 什么是LaTex
一款基于代码的排版工具，在写**实验报告、各种作业、论文排版**很常用。
相较于word，Latex的自动排版更加美观，可以实现的功能也更多。
### 如何入门Latex
1. 推荐**latex排版网站：overleaf**
（overleaf上非会员有编译限制，可以去taobao找代充会员）
2. 可以看一下本文件夹内的**latex官方说明文档**（这个文档非常长，里面包含了latex几乎所有公式，不可能全都看完，一上来的话可以先看一看基本介绍）
3. **熟能生巧，善用AI，现用现查**：latex里面公式宏包特别多，不可能全都会，这些都是要在使用的时候去查找然后用的。当然现在AI编程能力很强，可以让AI帮你写好代码模板，然后你往里面填写就行。b站上有很多讲解视频非常好。后面也会出一些常用公式模板合集和比较好的b站视频合集放在文件夹里。
4. 搜寻**overleaf模板**，南开的ppt、论文等等在这个网站上都有模板，可以参考
