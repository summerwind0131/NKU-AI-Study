# 教材
- 课内教材：华中科技大学《模拟电子技术》
- 可参考教材：清华大学童诗白版本的模电
    以上两本教材各有优劣，本人更喜欢清华大学教材先讲器件再引入放大器的叙事逻辑，并且清华版教材对于一些电路的设计思路有很多讲解
    此外华科那本教材习题册有个别题答案写错了，做的时候也要甄别一下——fyr
# 推荐网课
- 上海交大 郑益慧老师的网课：思路讲解非常清楚，对于电路设计背后的工程思维讲的也非常深入，非常好的课程——fyr
- New Analog Circuit Design by Hajimiri，Caltech：这个课主要偏向于物理，对于器件设计物理原理的非常感兴趣又有一定物理基础的同学可以看着玩，讲课质量相当高，老师个人主页里还有他的讲义。——fyr
# 备考策略
